# Sweet Tooth pixel palette (32 colors)

Shared by every background and sprite of the animated cozy loop (`docs/animated-cozy-loop-v5.md`). Outlines use `cocoa-900`, never black. Night is a cool tint over the same palette, not new colors. Transparency is separate.
