# MMSIM-10 — UI restyle v2 (Claude Design handoff)

Motivation: the Claude Design pass over the interface (briefed by MMSIM-9) came back as `design/design_handoff_sweet_tooth_v2/`: a restyle and re-layout of the five screens, a state sheet (upgrade cards, errands, focus ring), a 390 px phone layout and a logo/icon set. Structure, rules and information are unchanged; "high fidelity", so colours, type, spacing, radii and shadows were taken as fixed.

- IN:
  - **Design system**: `src/ui/tokens.css` (all colours, composite tokens, wood and parchment textures as CSS-only SVG-noise layers; light default, dark via `prefers-color-scheme`) and `src/ui/app.css` (wood `.frame`, flat `.card`, parchment `.note`, buttons `.btn` honey / `.btn2` wooden plate / `.btn3` outline, chips, focus ring `0 0 0 2px #1b1612, 0 0 0 5px #ffe08a`). Fonts self-hosted through `@fontsource` (Young Serif, Bricolage Grotesque variable, JetBrains Mono 500), so nothing is fetched from a font CDN. `tokens.css` was generated from the handoff's own `renderVals` logic.
  - **Components rewritten** against the view layer: `Header` (wood HUD: logo, day, phase pill, coins, phase button, language, settings; two rows and an icon button on phone), `StageStrip` (day pips, rival chip with a disclosure popover), `CraftScreen`/`Craft` (shelf, cauldron stage, batch circles, recipe cards, quality segmented control, 4-step track), `Serve` (2x2 customer cards, segmented patience meter, clerk card with switch and training bars, Latest), `Evening` (journal note, report figures, three-branch skill tree with the five upgrade states and branch colours, branch tabs on phone), `Errands` (collapsed rows that expand; available / rival / under way / ready / locked / done), `MapStrip`, `Settings`, `Board` (parchment note; collapsible "Today" card on phone), `Pips`, `ImageSlot` (scalable, striped fallback). Phone layout: one column, 8 px wood, fixed bottom action bar with the phase button (safe-area padding).
  - **View layer** (all new presentation state lives here, with tests in `src/view/design.test.ts`): header `phases`/`dayNo`/`coins`; stage `pips` (rival day marked), `chip`; serve `patienceMeter` (left/max/tier/label), `portrait`, labels, clerk training counters; board `stockChips` (rings = quality rank); errand `tone`/`chip`/`progress`; tree node `state` (owned, maxed, afford, short, locked) with `stateLabel`, `pips`, `lockReason`, `shortBy`, branch `glyph`/`affordText`; report `stats`; craft `scene` (shelf with pips, batches, in-cauldron lines), `recipes`, `qualityOptions`, step `track`; menu `startOver`/`note`. Max patience is derived (type base + patience upgrades), so **no state/save change**.
  - Strings (EN/FR parity kept): about 55 new keys; changed `craft.start` (Start batch), `serve.serve` ("Serve Plain · 5"), `tree.buy` ("Buy · 20"), `errands.locked` ("Requires X first."), `settings.close` (Back to the shop); the "Done" errand line is now "Reward received.".
  - Customer art slots (`customer-faithful|traveler|merchant|bee`, 96x120) with placeholder SVGs; the content check now requires one per customer type.
  - Logo and icon set copied to `public/brand/` (favicon, apple-touch icon, web manifest, theme colour) and linked from `index.html`.
  - `scripts/screenshots.ts` updated to the new DOM; `docs/design-brief/screens/` regenerated (17 PNGs).
- OUT: no gameplay, balance or save change; no motion (the handoff lists steam, stirring, drop, draining patience and coin burst as non-binding candidates); upgrade icons, bee, rival hive, Sweet Tooth and shop-background art slots (requested in the handoff, not shown in any screen); the "Swipe or tap Shop and Temple / Hive" hint (tabs alone are clear); `docs/design-brief/README.md` still describes the pre-restyle UI and weak points.
- Decisions taken where the handoff was silent or ambiguous:
  - The phase pill shows the day of the **week** (`n / 7`) like the stage strip, not the global day counter.
  - The red dot on the Today note is decorative.
  - Chip text for the other rival-warning variants: "Rival hive at work" (stealing now), "Rival hive next week", "Rival hive from day n" (handoff).
  - Quality options list all qualities and disable locked ones (handoff: "unavailable = 40% opacity, disabled"); recipes list only unlocked candies so locked ones are not spoiled.
  - Step note "tap" instead of the mock's "tap or circle" (circling does not exist yet).
  - The workshop sub-line "The old shack, before the pilgrims arrive" was left out (it would be wrong in later weeks).
  - Language moves into Settings on phone only; desktop keeps the EN button (it switches to the next language).
  - The disabled primary button (Deliver, Start batch) uses the dashed muted style the handoff gives for disabled Buy/Deliver.
- Verified: `npm run check`, `npm test` (161), `npm run check:content`, `npm run build`; played a whole day by hand at 1200 px and 375 px in the browser (craft idle and bench, serve, evening, settings), no console errors, no horizontal overflow on phone; screenshots checked in dark and light.
- Open decisions: art is still placeholder SVGs; French layout was not screenshot-checked (strings are in, text boxes have no fixed widths); the dev-server CSS glitch noted in `CLAUDE.md` did not appear.
