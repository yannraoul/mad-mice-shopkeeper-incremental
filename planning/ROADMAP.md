# Roadmap: Mad Mice Shopkeeper Incremental

Each entry below is a milestone with a **MMSIM-x** (Mad Mice Shopkeeper Incremental Milestone)
identifier — real, scoped features/scope changes, in commit order. Full detail
for each milestone lives in its own `features/MMSIM-x.md` file; this
file is just the index. Bugs found *after* the milestone that introduced them
has already shipped go in `CHANGELOG.md` instead (**MMSIB-y** ids), and
not-yet-scoped ideas live in `BACKLOG.md`. See `../instructions.md` for the
full convention (commit message pattern, when something is
MMSIM vs MMSIB, etc).
